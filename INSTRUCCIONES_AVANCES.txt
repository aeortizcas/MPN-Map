================================================================================
1. OBJETIVO DEL PROYECTO
================================================================================

Crear un mapa interactivo estilo Google Maps que muestre solo los Estados
Unidos, con las siguientes funcionalidades:

- Visualizacion del mapa de EE.UU. (interactivo, con zoom y arrastre)
- Georeferenciacion de ubicaciones (coordenadas GPS)
- Busqueda de lugares / direcciones (como Google Maps)
- Marcadores personalizables
- Info windows al hacer clic en marcadores

================================================================================
2. TECNOLOGIAS Y HERRAMIENTAS RECOMENDADAS
================================================================================

- HTML5 + CSS3 + JavaScript (vanilla o framework)
- Leaflet.js (libreria de mapas, gratuita, sin API key necesaria)
- OpenStreetMap como proveedor de tiles (gratuito)
- OR alternativamente: Google Maps JavaScript API (requiere API key)
- Busqueda: Leaflet Control Geocoder o Fuse.js para busqueda local
- Archivo GeoJSON de estados de EE.UU. para limites estatales

<!DOCTYPE html>
<html>

    <title>MPN Map - Estados Unidos</title>

    <div id="map"></div>
    <script src="lib/leaflet/leaflet.js"></script>
    <script src="js/map.js"></script>
</body>
</html>

Estructura basica de js/map.js:

const map = L.map('map').setView([39.8, -98.5], 4);
L.tileLayer('https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png', {
    attribution: 'OpenStreetMap'
}).addTo(map);

================================================================================
7. NOTAS Y CONSIDERACIONES
================================================================================

- Leaflet.js es gratuito y no requiere API key, ideal para proyectos personales
- OpenStreetMap tiene limite de 100,000 solicitudes por dia (tile cache)
- Para produccion, considerar un proveedor de tiles propio o pago
- GeoJSON de estados de EE.UU. es pesado (~1-2MB comprimido)
- La geolocalizacion del navegador requiere HTTPS en produccion
- El reverse geocoding con Nominatim tiene tasa de 1 req/segundo
